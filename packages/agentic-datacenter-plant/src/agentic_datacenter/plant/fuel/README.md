# fuel

Bulk storage, polishing, transfer pumps and one sub-base tank per generator with its level controller.

- Fidelity: `F1`
- Zone: `Z1-FUEL`
- Instances: one, for example `FUEL`; keys `trains`
- Spec: [`docs/design/modules/fuel.md`](../../../../../../docs/design/modules/fuel.md)

## Stub behaviour

Fuel is always available to every generator. No tank level, no pump, no power drawn.
