# cooling.weather

Dry-bulb temperature and humidity at the site, from a synthetic daily cycle or, with `source: measured`, from a measured series read through `agentic_datacenter.data` (ADR 0018).

- Fidelity: `F1`
- Zone: `Z1-BLDG`
- Instances: one, for example `SITE`
- Spec: [`docs/design/modules/cooling.weather.md`](../../../../../../../docs/design/modules/cooling.weather.md)

## Stub behaviour

Constant conditions.
