# sensors

The model every measured point passes through: accuracy, resolution, update period and failure modes.

- Fidelity: `F1`
- Zone: `n/a`
- Instances: one, for example `SENSORS`
- Spec: [`docs/design/modules/sensors.md`](../../../../../../docs/design/modules/sensors.md)
