# life_safety

The hardwired layer: fire alarm panel, air-sampling detection per POD, cause and effect, emergency power off and the fire pump.

- Fidelity: `F1`
- Zone: `Z0-PROT`
- Instances: one, for example `LS`; keys `pods`
- Spec: [`docs/design/modules/life_safety.md`](../../../../../../docs/design/modules/life_safety.md)

## Stub behaviour

Nothing ever happens: no fire, no emergency power off, no fire pump start.
