Agentic-Datacenter demonstration run

development run, not a benchmark result The same plant, scenario and seed (1) played twice: with no gate, and with the gate static_allowlist. Lowest module fidelity: F1. Read-only: nothing on this page acts on anything.

  • These are simulation results. A simulator is not a facility and no claim transfers to one automatically.
  • No module is calibrated against measurements from a real facility (fidelity F3). Plant sizing and several sequences are engineering assumptions.
  • Treating an AI agent as a software process under IEC 62443-3-3 SR 1.2 and SR 2.1 is this project's interpretation. No IEC 62443 certification is claimed.

The design document's demonstration compares UNGOVERNED against GOVERNED. This run was made with a gate of another operating profile, so the right-hand side is the profile named on it. Here: STATIC_ALLOWLIST, which is not governed execution.

In each chart the solid line is the supply air of the hottest POD and the dashed line the chilled water setpoint, both in °C. A red mark on the time axis is a blocked proposal. Every proposal links to its decision record; a blocked one also says what the replay found when the same proposal was executed from the same instant.
