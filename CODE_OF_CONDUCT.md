# Code of conduct

Agentic-Datacenter follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the repository's issues, pull requests and reviews, and wherever someone speaks for the project.

## Reporting

Report conduct that breaks it privately, not in a public issue. Use either:

- the private reporting form on the repository's **Security** tab ("Report a vulnerability"), as described in [`SECURITY.md`](SECURITY.md), and say in the title that it is about conduct; or
- the contact address in [`COMMERCIAL_LICENSING.md`](COMMERCIAL_LICENSING.md), with "Code of conduct" in the subject.

Say what happened, where, and when. A link to the comment or issue helps. The maintainer reads every report, keeps the reporter's name private, and replies to say what is done. The enforcement guidelines of the Covenant apply.
